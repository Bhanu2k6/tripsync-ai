# ✈️ TripSync AI

TripSync AI is an AI-powered travel planning web application that helps users generate personalized travel itineraries instantly.

## 🌍 Live Demo

https://tripsync-ai.vercel.app/

---

## 🚀 Features

- 🤖 AI-generated travel itineraries
- 🌤️ Real-time weather information
- 🗺️ Interactive Google Maps integration
- 📍 Nearby places recommendations
- ❤️ Wishlist system
- 🕘 Trip history dashboard
- 📄 PDF trip download
- 🔐 Google Authentication
- ✨ Modern responsive UI
- 🎒 AI-generated travel tips & packing suggestions

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### APIs & Services
- OpenRouter AI API
- Weather API
- Places API
- Firebase Authentication

### Deployment
- Vercel
